# 影径 · The Shadow Path

一个关于灯与影的等距小游戏：皮影小人只能走在影子里，转动灯笼，让影子替她铺出一条通往月门的路。

**在线试玩：** https://wywwywwywwywwyw.github.io/silent-spire/

## 玩法

- 影子里的石板会浮现蓝色纹样，轻点它们，她会自己找路走过去
- 拖动灯笼让它绕着灯杆转，或轻点灯笼转 45°（电脑上按 R，Shift+R 反向）
- 灯光不能照到她：如果再转下去光会落在她身上，灯笼会停住

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) r128 的正交相机画等距视角。灯笼是一盏带阴影的点光源，“能不能走”用和画面阴影相同的几何体做光线检测：每块石板取 5 个采样点，至少 3 个看不见灯笼就算影子。音效由 Web Audio 实时合成，拨弦用的是 Karplus-Strong 算法。

第一版纪念碑谷风格的 demo《静默之塔》在 git 历史里。
