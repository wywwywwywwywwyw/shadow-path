# 影径 · The Shadow Path

一个关于光与影的等距小游戏：墨水小精灵“小墨”只能待在影子里，转动光球，让雕塑的影子替它铺出一条回到暗门的路。

**在线试玩：** https://wywwywwywwywwyw.github.io/silent-spire/

## 玩法

- 影子里的石板会浮现墨点，轻点它们，小墨会自己找路走过去
- 拖动光球让它绕着立杆转，或轻点光球转 45°（电脑上按 R，Shift+R 反向）
- 光不能照到小墨：如果再转下去光会落在它身上，光球会停住

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) r128 的正交相机画等距视角。光球是一盏带阴影的点光源，“能不能走”用和画面阴影相同的几何体做光线检测：每块石板取 5 个采样点，至少 3 个看不见光球就算影子。音效由 Web Audio 实时合成。

更早的两个版本（纪念碑谷风格的《静默之塔》、中式庭院版《影径》）在 git 历史里。
