# 影径 · The Shadow Path

一个关于光与影的等距小游戏：旅人只能走在影子里。在漂浮的庭院中转动光球、推动小塔、升降石柱，让影子替她铺出一条通往那扇门的路。

**在线试玩：** https://wywwywwywwywwyw.github.io/silent-spire/

## 关卡

左上角可以随时选关。

- **I · 黄昏**：只有一盏可以绕杆转动的光球。转 4 次，每次走一段。
- **II · 清晨**：多了一座能沿地面凹槽推动的小塔。光球决定影子朝哪边倒，小塔决定影子落在哪里。
- **III · 星夜**：多了一根升降柱，有三个高度。升高时投下长影，降到底就和地面齐平，成了一块能踩的石板。它得先降下来让她踩过去，再升起来替她挡光：把柱子停在任何一个高度不动，或者只降不升、只升不降，都到不了门口。

进度保存在浏览器里，刷新后会回到上次所在的关卡；通关过的章节在选关菜单里有个小菱形。

## 玩法

- 轻点影子里的石板，旅人会自己找路走过去；点到有光的石板会闪一下，她过不去
- 光球、第二章的小塔、第三章的柱子都可以拖动，松手后吸附到最近的一档
- 也可以直接轻点它们：每点一下动一格，走到头就往回；被挡住时会晃一下，再点就换个方向
- 电脑上：R / Shift+R 转光球，← → 推塔，↑ ↓ 升降柱子
- 柱子降到底就和地面齐平，她可以从上面走过去
- 光不能照到她：如果再转、再推、再升降下去光会落在她身上，机关会停住；塔推不过她站的格子，她站在柱子上时柱子也升不起来

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) r160 的正交相机画等距视角，画面沿用第一版《静默之塔》的平涂风格，每一章换一套配色。three.js 和字体都随页面放在 [`vendor/`](vendor/) 里，不依赖外部 CDN；中文字体只保留页面用到的字，约 70 KB。光球是一盏带阴影的点光源，“能不能走”用和画面阴影相同的几何体做光线检测：每块石板取 5 个采样点，至少 3 个看不见光球就算影子。三关的布局都由求解脚本搜索并验证过：每一关都必须用到它提供的全部机关，第三关还排除了“把柱子设一次就不管”的解法。关卡数据是 `index.html` 里的一段 JSON，游戏和求解脚本读的是同一份；求解脚本在 [`tools/solver/`](tools/solver/)，`python tools/solver/verify_levels.py` 可以复核三关。音效由 Web Audio 实时合成。

之前的各个版本都在 git 历史里。
