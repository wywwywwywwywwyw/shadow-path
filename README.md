# 影径 · The Shadow Path

一个关于光与影的等距小游戏：旅人只能走在影子里。在黄昏里漂浮的庭院中转动光球，让小塔和矮墙的影子替她铺出一条通往那扇门的路。

**在线试玩：** https://wywwywwywwywwyw.github.io/silent-spire/

## 玩法

- 轻点影子里的石板，旅人会自己找路走过去；点到有光的石板会闪一下，她过不去
- 拖动光球让它绕着立杆转，或轻点光球转 45°（电脑上按 R，Shift+R 反向）
- 光不能照到她：如果再转下去光会落在她身上，光球会停住

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) r160（ES 模块，从 jsDelivr 加载）的正交相机画等距视角，画面沿用第一版《静默之塔》的平涂粉紫风格。光球是一盏带阴影的点光源，“能不能走”用和画面阴影相同的几何体做光线检测：每块石板取 5 个采样点，至少 3 个看不见光球就算影子。音效由 Web Audio 实时合成。

之前的各个版本都在 git 历史里。
