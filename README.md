# 影径 · The Shadow Path

一个关于光与影的等距小游戏：旅人只能走在影子里。在漂浮的庭院中转动光球、推动小塔，让影子替她铺出一条通往那扇门的路。

**在线试玩：** https://wywwywwywwywwyw.github.io/silent-spire/

## 关卡

- **第一章 · 粉紫黄昏**：只有一盏可以绕杆转动的光球。转 4 次，每次走一段。
- **第二章 · 海边清晨**：多了一座能沿地面凹槽推动的小塔。光球决定影子朝哪边倒，小塔决定影子落在哪里，两样都得用上。

进度保存在浏览器里，刷新后会回到上次所在的关卡。

## 玩法

- 轻点影子里的石板，旅人会自己找路走过去；点到有光的石板会闪一下，她过不去
- 拖动光球让它绕着立杆转，或轻点光球转 45°（电脑上按 R，Shift+R 反向）
- 按住第二章的小塔沿凹槽拖动，它会一格一格地吸附
- 光不能照到她：如果再转、再推下去光会落在她身上，机关会停住；塔也推不过她站的格子

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) r160（ES 模块，从 jsDelivr 加载）的正交相机画等距视角，画面沿用第一版《静默之塔》的平涂风格，每一章换一套配色。光球是一盏带阴影的点光源，“能不能走”用和画面阴影相同的几何体做光线检测：每块石板取 5 个采样点，至少 3 个看不见光球就算影子。两关的布局都由求解脚本搜索并验证过：每一关都必须用到它提供的全部机关。音效由 Web Audio 实时合成。

之前的各个版本都在 git 历史里。
